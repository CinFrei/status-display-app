## Acknowledgements

This repository includes a customized version of the VNC kiosk server originally developed by [bishopdynamics](https://github.com/bishopdynamics).

**Modifications**:

- The password was changed (the original developer used 'space' as a placeholder).
- Added landscape extension to simplify view rotation
- Some parts of the Docker Compose configuration were removed or adjusted to simplify the setup for use with the **Status-Display-App**.

For more information, you can refer to the original [README](https://github.com/bishopdynamics/kindle-touch-kiosk/tree/main) and [KIOSK section](https://github.com/bishopdynamics/kindle-touch-kiosk/tree/main/docker-vnc-kiosk-server).
